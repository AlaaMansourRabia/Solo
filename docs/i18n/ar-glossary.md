# Arabic (ar-SA) translation glossary

Modern Standard Arabic (فصحى). Used for `docsAr`, block/template
`displayNameAr`/`descriptionAr`, and the docs registry. Keep terminology
consistent with this table.

## Never translate

- Component, hook, package, type and prop names: `Button`, `useToast`,
  `@solo/core`, `ReactNode`, `isDisabled`, `className`…
- Anything in `backticks`, code, CSS, token names (`--color-accent`), ARIA
  roles/attributes (`aria-label`, `role="menu"`), keys (`Enter`, `Escape`),
  HTML elements (`<button>`), file names, URLs.
- Prop values in quotes: `'primary'`, `'sm'`.
- Brand/product names (Solo, Tailwind, React).

Keep backticks, quotes and punctuation inside code exactly as in English. Use
Arabic punctuation in prose: ، ؛ ؟ and keep numbers as Western digits (0–9).
